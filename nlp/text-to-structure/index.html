Break it

Correct words can still produce
the wrong business action.

Failure experiments reveal where shallow language processing destroys distinctions, ignores context or extracts correct entities while missing the relationship that matters.

Failure 01 · normalization

Stemming destroys useful form

Mechanical reduction can make different terms look more similar than their meanings justify.

Run the test.
Failure 02 · context

Same token, different role

“ship” can be a verb or a noun. Surface lookup alone is insufficient.

Run the test.
Failure 03 · ambiguity

Jordan called Paris

Entity names can support multiple plausible interpretations. Silent certainty is a system defect.

Run the test.
Failure 04 · relationships

Negation changes the action

All entities may be individually correct while “Do not send before Friday” is reconstructed incorrectly.

Mechanical reduction can be fast and useful for rough matching, but may produce non-words or collapse distinctions.

Lemmatization

Linguistically informed normalization aims to preserve meaningful base forms and is usually better when semantic precision matters.

filters → filter
better → good
running → run
Normalization is not automatically an improvement. Choose it according to what the downstream system must preserve.
