Predict / Decide

Map the incoming request into a bounded operational route, then apply a confidence gate before continuing.

message → candidate routes → lab scores → threshold / margin → selected route or clarification

Generate / Construct

Once the route and context are known, construct a response under business constraints and validation.

route + context → response instruction → constrained draft → validation → human review / send
